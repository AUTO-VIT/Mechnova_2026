# Make Tweakable

Make sure the design supports Tweaks. If the user specifies what should be tweakable, do that. Otherwise pick a few high-impact values — key colors, a layout variant, a feature flag, headline copy. Keep the Tweaks panel small and tasteful; hide it completely when Tweaks is off.
