# CSS Grid & Flexbox Masterclass

Layout patterns:
- Use CSS Grid for 2D multi-dimensional layouts and card matrices (`grid-template-columns: repeat(auto-fit, minmax(280px, 1fr))`).
- Use Flexbox for 1D component alignments (navigation bars, button groups, icon text inline rows).
- Utilize Container Queries (`@container`) to make components responsive to their container width instead of viewport width.
- Use `gap` property instead of margin hacks for spacing grid and flex children.
