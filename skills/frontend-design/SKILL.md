# Frontend Design

Use this guidance only when UI work is NOT governed by an existing brand/design system (not applicable while the attached design system is in force).

## Design Thinking
Before coding, commit to a BOLD aesthetic direction:
- **Purpose**: what problem, who uses it
- **Tone**: pick an extreme (brutally minimal, maximalist, retro-futuristic, organic, luxury, playful, editorial, brutalist, art deco, soft/pastel, industrial...)
- **Differentiation**: what makes it unforgettable

## Aesthetics Guidelines
- **Typography**: distinctive display font + refined body font; avoid generic (Arial, Inter)
- **Color & Theme**: cohesive palette via CSS variables; dominant colors with sharp accents
- **Motion**: CSS-first; one well-orchestrated staggered reveal beats scattered micro-interactions
- **Spatial Composition**: unexpected layouts, asymmetry, overlap, diagonal flow, grid-breaking
- **Backgrounds**: gradient meshes, noise, patterns, layered transparency, shadows, grain — avoid flat solids

Vary choices across generations; never converge on the same look. Match implementation complexity to the aesthetic (maximalist = elaborate, minimalist = restraint/precision).
