# UI/UX Pro Design Principles

Guidelines for premium user interface design:
- Establish a dominant visual hierarchy: clear primary action, distinct secondary actions.
- Use curated, harmonious color palettes with high contrast text.
- Maintain consistent spacing rhythms (4px/8px base grid).
- Provide clear loading states, skeleton loaders, and graceful empty states.
- Avoid clutter; eliminate non-essential decorative elements.
