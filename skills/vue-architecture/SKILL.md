# Vue 3 Architecture & Composition API

Guidelines for Vue 3 applications:
- Use `<script setup>` syntax for concise, performant Single File Components.
- Utilize composables (`useFeature.js`) for reusable reactive logic.
- Use Pinia for centralized state management instead of Vuex.
- Enforce strict typing with TypeScript and Volar.
