# Angular Pro Architecture

Guidelines for Angular development:
- Use Standalone Components (`standalone: true`) to eliminate module boilerplate.
- Leverage Angular Signals (`signal()`, `computed()`) for fine-grained reactivity.
- Manage asynchronous data streams cleanly with RxJS pipes and `async` pipe in templates.
- Enforce strict typing, dependency injection best practices, and OnPush change detection strategy.
