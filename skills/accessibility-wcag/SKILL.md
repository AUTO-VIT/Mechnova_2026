# Web Accessibility (WCAG 2.1 AA)

Accessibility requirements:
- Use semantic HTML tags (`<header>`, `<nav>`, `<main>`, `<article>`, `<button>`).
- Provide explicit `aria-label` or `aria-labelledby` for icon-only buttons.
- Ensure high contrast ratios (minimum 4.5:1 for normal text, 3:1 for large text).
- Manage keyboard focus states with visible `focus-visible:ring-2` outlines.
- Include `alt` text for all informative images and decorative `aria-hidden="true"` for decorative icons.
