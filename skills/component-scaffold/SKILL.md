# Component Scaffolding Standard

Pattern for UI components:
- Structure components with explicit props interfaces, default values, and clean export statements.
- Decouple layout wrapper components from presentation cards.
- Export components via index barrel exports where appropriate.
- Include JSDoc comments detailing key component props and visual variants.
